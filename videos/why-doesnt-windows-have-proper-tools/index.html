Why Doesn't Windows Have Proper Tools?

13 min2026-09-24

And the first thing a serious Windows user does on a new machine is install somebody else's file manager, somebody else's search, somebody else's archive tool. Before any actual work, they rebuild the toolbox.

The file manager is the sharpest case. A two-panel one has existed since 1993 — and for its first nine years it was not called Total Commander. It was called Windows Commander, until a letter arrived from lawyers representing the owner of that trademark. So Microsoft did not build that tool. Microsoft made it change its name.

1:14A program that has done all of it since 1993

2:34Finding a file, and where Windows is right

Finding a file. For years, the reliable answer was a tiny program called Everything. You type three letters. The results are already there. No waiting. No wondering whether the index has got round to your folder yet. And this one deserves a fair hearing, because the trick is not magic. On an NTFS drive there is a master file table, a list of everything on the disk. Everything reads that list once, then follows the change journal the filesystem is already keeping. That is why it feels instant. Windows Search is slower because it is doing a harder job.

It reads inside your documents, and it respects who is allowed to see which file. So that one is not a failure. It's a different question being answered. Hold on to that, because it is the exception.

3:31Disk space, copying, archives, screenshots

Where did the disk space go? Windows tells you that you have used nine hundred gigabytes. Where? And you end up installing a program that draws you a map. And what about copying files? Historically, if one file failed, Explorer cancelled the whole copy. Which files made it? Where do I pick it up? Can I skip just that one? So people installed something that would skip it, carry on, and tell them what it skipped. Deleting has a different mystery. That one has a whole video of its own. What about archives? Windows opens a zip file.

But there is a difference between supporting a format… …and giving someone a good tool for it. Screenshots. Print screen, open Paint, paste, crop. You had to do that for about twenty years.

4:28A program that watched other programs install

And uninstalling software is where it gets genuinely strange. Programs left files behind. Registry entries. Folders nobody would ever find. So people installed better uninstallers. But some of those uninstallers had a stranger job than that. They watched. You ran them first, then you ran the installer, and they recorded what changed. Think about what that means. You installed a program to watch another program install itself. Because Windows itself did not necessarily know.

5:09Not responding

Which brings us to the sharpest case. Not responding. Task Manager knows. It says so on the screen. But if you want to know why, you install Process Explorer. Threads. Handles. Which file the program is waiting on. Which process started it.

5:30Microsoft bought the company behind it

And Process Explorer came from a company called Sysinternals. Microsoft bought them. That was in 2006. And they got the man who wrote it. Mark Russinovich. Today, he is the CTO of Azure. Microsoft has owned that tool, and the person who wrote it, for twenty years. They host the download themselves. And it is still not in Windows.

6:00So it cannot be that they couldn't

So the answer cannot be that Microsoft couldn't. Which means the real question was never why they failed. It's why they chose not to.

6:12One: Windows was sold as a platform

There are three explanations. Only one of them has court records. Keep an eye on which. The first is the one everybody already knows. Windows was sold as a platform. Microsoft did not want to own every application on your computer. They wanted to own the floor it all stood on. Need a file manager? Somebody will build one. Need a disk tool? Somebody will build one. And that worked spectacularly. But on its own it explains nothing, because Apple sells a platform too, and Apple ships a screenshot tool.

6:52Two: this one has court dates

So here is the second reason, and this one has court dates. In 1998, the American government took Microsoft to court. Not for writing a bad browser. For putting it in Windows.

A judge ordered the company to be split in two. That order was thrown out on appeal, and the case settled in 2001. And the question underneath it, whether putting the browser in Windows was legal at all, was never actually answered.

Then in 2004, the European Commission fined them nearly half a billion euros. And ordered them to ship a version of Windows with the media player taken out. Look at that sentence again. A regulator required Microsoft to remove a tool from Windows.

7:48Not ancient history

And this is not ancient history. Starting in 2016, an antivirus company complained to regulators in Russia, then in Germany, then in Brussels. Because Windows had started defending itself. They withdrew the complaints in 2017, once Microsoft agreed to change how it behaved.

So put yourself in that meeting room. Somebody proposes shipping the best archive tool on the market, for free, to a billion machines. There is a market for archive tools. Shipping the best possible tool is the most expensive thing Microsoft can do.

And only for Microsoft. A smaller company could ship exactly the same tool and be fine. Once you are dominant, competition law limits how you can use that position. And replacing the very companies that built their business on your platform can start to look a lot like abusing it. Microsoft was trapped by its own success.

8:54Three: what the box costs

And the third reason is the quietest one. Putting something in Windows means supporting it for the next twenty years. It has to keep working. It can never be removed. It becomes somebody's whole workflow by Thursday. Which is why, in 1996, Microsoft did something revealing. They released a set of their own Windows utilities called PowerToys. Written by Microsoft engineers. Downloaded separately. And officially unsupported. We made these. They're good. We are not putting them in the box.

9:33Twenty programs, twenty updaters

And that same rule explains the biggest gap of all. Twenty programs. Twenty updaters. One checks at startup. One installs a service. You log in on a Monday and six of them want your attention before you have opened anything. Linux solved this decades ago. One command updates everything. So why couldn't Windows?

9:58Why Windows had no such command

Because that command works for a reason people forget. A Linux distribution builds the software itself. It compiles it, packages it, and knows what is in it. Microsoft does not build your software. Windows is not a distribution. It is a floor that anyone may put anything on. Which is exactly why that installer-watching program existed. Nobody had the list. Not even Windows.

10:30So that is the answer

So that is the answer. Platform, lawsuits, and the weight of anything you put in the box.

Except something has changed.

10:41Except something has changed

Because Windows now has a package manager. It arrived in 2021. One command, and your programs update. Windows has a proper terminal now. It runs Linux. PowerToys came back in 2019, open source.

10:59So why now?

So why now? Partly because the thing being protected has moved. Windows is not where Microsoft makes its money any more. It now sits in the smallest of the company's three divisions. That division brings in less than a fifth of the revenue. It also contains the Xbox. And nobody is going to court over a screenshot tool. The fight moved to browsers, then to phones, then to the data centre. The desktop is no longer the thing being defended.

But look closely at what shipped. PowerToys, you download yourself. Process Explorer, you download yourself. Sysinternals, you download yourself. Thirty years later, Microsoft still keeps its best tools one step outside Windows.

11:53The strange result

So the strange result stands. Microsoft built a platform so successful that other people built everything missing from it. And because those tools existed, Microsoft never had to. And for years, doing too much carried legal risk. Windows turned out to be extraordinarily good at hosting the tools it never shipped itself.

The user paid for that in complexity. A better file manager. A better search. Every one of them updating separately. Which means the real Windows experience was never install it and you're done. It was: install Windows. Then build your own operating environment around it. And the strangest part isn't that Microsoft couldn't do it. It's that for twenty years, being brilliant at this was the one thing Windows could not afford to be.
