Why Does Windows Only Have One Desktop?

10 min2026-11-11

This video goes through the setting that decides what your desktop is, the two jobs Explorer does, the replacement desktops people bought in the early nineties, LiteStep and the community that grew up around it, Blackbox, bbLean and Emerge Desktop, Cairo Desktop and Seelen UI on Windows 11 today, and an official Microsoft feature you may have used on a ticket machine without knowing.

This isn't a how-to: changing the Shell value without a working replacement can leave you with no desktop at all.

Watch on YouTubeSubscribe on YouTube

The full narration of the video.

0:00A desktop with no taskbar

Picture switching on a Windows PC and finding no taskbar, no Start button, and not a single icon on the desktop. Instead there's a thin bar along the top, a menu that pops up wherever you click, and four virtual desktops side by side. It looks like Linux. But your programs, your drivers and your files are exactly where you left them. It's still Windows.

0:25One setting

Only the desktop has changed. And the switch that changes it is a single setting. Windows keeps it in the registry, in a value called Shell. On almost every Windows PC, it says explorer.exe. Write the name of a different program there, sign out and sign back in, and Windows starts that program instead. Whatever it draws becomes your desktop.

0:50Windows 3.0, 1990

And this isn't a trick someone found last year. In 1990, Windows 3.0 had the same switch in a plain text file called system.ini. One line: shell=progman.exe. If you changed that name, Program Manager, the window full of icon groups, never appeared at all.

1:11The real question

So the question isn't whether Windows can have a different desktop. It always could. The question is why almost nobody has seen one.

1:22Explorer's two jobs

Start with what that line actually points to. The taskbar, the desktop icons, the little tray by the clock: all of that is one program, Explorer. Yes, the same Explorer you open to look through your files. It does two jobs, and most people only ever notice one. That second job has a name: the shell. It's the layer you touch. Underneath it sit the kernel, the drivers, and the services that keep Windows running. None of them need a taskbar. End Explorer in Task Manager, and the taskbar and icons vanish… but Notepad, your browser, every other window keeps working.

Start it again, and the desktop comes back. That's about the clearest proof there is that the desktop is just another program.

2:12On Android, it's a setting

If you've ever changed the launcher on an Android phone, you've seen a similar idea. Android makes it a normal setting. Windows has the mechanism too, but never gave ordinary users a simple button for it.

2:26Shell, window manager, desktop

Three words get mixed up here. The shell is what you launch things from: the taskbar, the menus, the desktop. A window manager controls how windows are positioned, stacked and focused. A desktop environment brings the whole experience together. On Linux, these pieces can be combined in many different ways. On Windows, replacing the shell doesn't replace the system's window management, or the way applications draw their window frames.

2:57Norton Desktop and Packard Bell

That didn't stop people from trying. By the early nineties, you could walk into a shop and buy a replacement for Program Manager. Norton Desktop for Windows gave you its own desktop, its own file tools and its own launcher, on top of the same Windows underneath. Some computer makers replaced it before the customer ever switched on. Packard Bell's Navigator greeted buyers with a house you could walk through, room by room. Then Windows 95 handed the job to Explorer, and the line in system.ini simply changed to explorer.exe. The switch stayed exactly where it was.

3:40LiteStep

In the late nineties, a whole community grew up around that switch. The best-known project was LiteStep. It borrowed its look from AfterStep, a Unix window manager modelled on NeXTSTEP, from the company Steve Jobs founded after leaving Apple. LiteStep had no Start menu unless you built one. Everything was a module: a dock here, a clock there, a menu that opened wherever you right-clicked. Its themes were shared like wallpapers. Some looked futuristic. Some looked like a Unix workstation. Some left almost nothing on the screen at all.

4:18Blackbox, bbLean and Emerge

Blackbox for Windows went the other way. It copied Blackbox, a minimalist Unix window manager, down to a single plain menu and a slim toolbar. Its successor, bbLean, kept that idea alive on Windows 2000 and XP. Emerge Desktop broke the shell into separate parts: a launcher, a tray, a task list, each one a small program you could keep or drop.

4:44Why go to all that trouble?

Why go to all that trouble? Partly because the look of XP was easy to recognise and hard to change. Themes changed the colours and buttons. The layout stayed. Partly memory. On a machine with a hundred and twenty-eight megabytes, a lighter shell promised more room for everything else. And partly Linux. There, choosing your desktop was normal, and some Windows users wanted the same choice.

5:12Where did they go?

Most of those projects are gone now. LiteStep's last release was a preview from 2014, still marked alpha. Emerge Desktop and SharpEnviro stopped too.

Small volunteer teams were part of the reason. But Windows changed too. Over the years, its desktop became much more than one executable. The desktop experience is now spread across multiple processes, system components and packaged applications. Even the Start menu runs as a program of its own. Replacing Explorer doesn't mean replacing everything that makes up the modern Windows interface. And that's one reason why building a complete alternative desktop is harder than it used to be.

6:02Cairo Desktop

And yet it still works. Cairo Desktop, an open-source project, runs on Windows 11 today. It brings its own menu bar along the top, its own taskbar, and folders you can pin to the bar as stacks. It can run alongside Explorer, or take over as the shell. In that second mode, parts of Windows 11 can misbehave, Settings and Windows Security among them.

6:28Seelen UI

Seelen UI goes about it differently. It doesn't replace Explorer. It hides the taskbar and brings its own pieces: a dock, a bar, widgets, and a window manager that tiles your windows. The result can look nothing like Windows. But underneath, Explorer is still running. It's a new face, not a new shell.

6:52What about Microsoft?

And Microsoft? It actually has an official feature for this. It's called Shell Launcher, and it's designed for devices like kiosks. You've probably used something like it without knowing. The ticket machine at a station. A self-service checkout. A cash machine. Many of them are Windows PCs whose whole shell is one application. An administrator names the program, and after sign-in, that program is the whole desktop. But it's only available in the Enterprise, Education and IoT Enterprise editions. And the older registry mechanism is still part of Windows. Microsoft just never turned it into a normal desktop setting for ordinary users.

7:40So why only one?

So why does Windows only seem to have one desktop? Not because it can't have another. Because the desktop is the product.

7:52A choice on Linux

On Linux, the desktop is a choice. Some distributions ask you to pick one while you're still installing. KDE Plasma, GNOME, Xfce, Cinnamon… On Windows, the desktop is what Microsoft shows in every advert, every screenshot and every support page. One desktop means one set of instructions for more than a billion machines. That's a real advantage. When something breaks, the screen in the help article looks like yours. The cost is that most people never learn there was a choice.

8:28Before Windows 95

People were swapping the Windows desktop before Windows 95 even existed. They built docks, bare menus, and desktops that looked like nothing else. Most of those projects are gone. The idea isn't. Under every taskbar you've ever clicked, there's still that one setting, waiting for a different name. The desktop is just another piece of software. And software can be replaced.

So here's a question for you. If Windows let you pick your desktop while installing, the way some Linux distributions do, would you switch, or keep the one you know? Let me know in the comments.
