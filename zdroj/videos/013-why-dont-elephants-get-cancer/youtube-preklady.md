(`paradoxe de Peto`, `Petos Paradox`, `Petovu paradoxu`…).

## Kontrola čísel: tady je ta nejhorší past kanálu

Anglické **„thirty trillion cells"** je 3 · 10¹³. To **není**
„třicet trilionů" — je to:

| | |
|---|---|
| cs, de, sv | **30 bilionů** / `dreißig Billionen` / `trettio biljoner` |
| fr | `trente mille milliards` (opis, protože francouzský *billion* je 10⁹) |
| it | `trentamila miliardi` (týž důvod) |
| es | `treinta billones` |
| pl | `trzydziestu bilionów` |
| pt-BR | `trinta trilhões` (brazilská krátká škála — tady *trilhão* opravdu je 10¹²) |

Všechny tyhle tvary jsou **převzaté z přeložených scénářů**, ne moje.
Dál se kontroluje **dvacet kopií** TP53 a letopočty ve zdrojích.
