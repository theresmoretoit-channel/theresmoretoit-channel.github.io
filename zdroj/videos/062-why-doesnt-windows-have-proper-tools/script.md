<!-- S01 -->
Microsoft has the source code to Windows.
They wrote the APIs.
They know exactly how it works inside.

<!-- S02 -->
They have had thirty years,
and some of the largest engineering teams
in the history of software.

<!-- S03 -->
And yet.

<!-- S04 -->
Watch what a serious Windows user does
on a brand new machine.

<!-- S05 -->
They install a different file manager.
A different search tool.
A different archive program.

<!-- S05b -->
Image viewer.
Video player.
Music player.

<!-- S05c -->
PDF reader.
Text editor.

<!-- S05d -->
And the list goes on...

<!-- S06 -->
Before they do any actual work,
they rebuild the toolbox.

<!-- S07 -->
So here is the question.
Why doesn't Windows come with the tools
you need the moment the work gets harder?

<!-- S08 -->
Start with the file manager.

<!-- S09 -->
If you only want to open a folder
and double-click a document,
File Explorer is fine.

<!-- S10 -->
But if you need to do more with files...

<!-- S11 -->
Compare two folders and sync them.
Rename three hundred files by a pattern.
See folder sizes without opening each one.

<!-- S12 -->
And you discover a program
that has been doing all of that
since 1993.

<!-- S13 -->
Two panels.
Keyboard shortcuts.
Synchronise. Compare. Rename. Archive.

<!-- S14 -->
Written by one developer.
In Switzerland.
Called Christian Ghisler.

<!-- S15 -->
And here is the part
that says more than the feature list.

<!-- S16 -->
For the first nine years,
it was not called Total Commander.

<!-- S17 -->
It was called Windows Commander.

<!-- S18 -->
Then in the summer of 2002,
a letter arrived from a firm of lawyers.

<!-- S19 -->
They represented, in their own words,
the owner of the trademark Windows.

<!-- S20 -->
So Microsoft did not build that tool.
Microsoft made it change its name.

<!-- S21 -->
And before you decide
that nobody in Redmond ever had the idea
of a proper two-panel file manager...

<!-- S22 -->
They did have it.
They shipped it.

<!-- S23 -->
DOS Shell, 1988.
Left panel, right panel.
In the box.

<!-- S24 -->
Microsoft removed it.

<!-- S25 -->
So the question sharpens immediately.
This isn't a gap nobody noticed.

<!-- S25b -->
By the way, if you like videos
like this, consider subscribing.

It really helps the channel.

<!-- S26 -->
Keep going, because the pattern repeats.

<!-- S27 -->
Finding a file.

<!-- S28 -->
For years, the reliable answer was
a tiny program called Everything.

<!-- S29 -->
You type three letters.
The results are already there.

<!-- S30 -->
No waiting.
No wondering whether the index
has got round to your folder yet.

<!-- S31 -->
And this one deserves a fair hearing,
because the trick is not magic.

<!-- S32 -->
On an NTFS drive
there is a master file table,
a list of everything on the disk.

<!-- S33 -->
Everything reads that list once,
then follows the change journal
the filesystem is already keeping.

<!-- S34 -->
That is why it feels instant.

<!-- S35 -->
Windows Search is slower
because it is doing a harder job.

<!-- S36 -->
It reads inside your documents,
and it respects
who is allowed to see which file.

<!-- S37 -->
So that one is not a failure.
It's a different question
being answered.

<!-- S38 -->
Hold on to that,
because it is the exception.

<!-- S39 -->
Where did the disk space go?

<!-- S40 -->
Windows tells you
that you have used nine hundred gigabytes.

<!-- S41 -->
Where?

<!-- S42 -->
And you end up installing
a program that draws you a map.

<!-- S43 -->
And what about copying files?

<!-- S44 -->
Historically, if one file failed,
Explorer cancelled the whole copy.

<!-- S45 -->
Which files made it?

<!-- S45b -->
Where do I pick it up?
Can I skip just that one?

<!-- S46 -->
So people installed something
that would skip it, carry on,
and tell them what it skipped.

<!-- S46b -->
Deleting has a different mystery.
That one has a whole video of its own.

<!-- S47 -->
What about archives?
Windows opens a zip file.

<!-- S48 -->
But there is a difference between
supporting a format...

<!-- S49 -->
...and giving someone a good tool for it.

<!-- S50 -->
Screenshots.
Print screen, open Paint, paste, crop.

<!-- S51 -->
You had to do that for about twenty years.

<!-- S52 -->
And uninstalling software
is where it gets genuinely strange.

<!-- S53 -->
Programs left files behind.
Registry entries.
Folders nobody would ever find.

<!-- S54 -->
So people installed
better uninstallers.

<!-- S55 -->
But some of those uninstallers
had a stranger job than that.

<!-- S56 -->
They watched.

<!-- S57 -->
You ran them first,
then you ran the installer,
and they recorded what changed.

<!-- S58 -->
Think about what that means.

<!-- S59 -->
You installed a program
to watch another program
install itself.

<!-- S60 -->
Because Windows itself
did not necessarily know.

<!-- S61 -->
Which brings us to the sharpest case.

<!-- S62 -->
Not responding.

<!-- S63 -->
Task Manager knows.
It says so on the screen.

<!-- S64 -->
But if you want to know why,
you install Process Explorer.

<!-- S65 -->
Threads.

<!-- S65b -->
Handles.

<!-- S65c -->
Which file the program is waiting on.
Which process started it.

<!-- S66 -->
And Process Explorer
came from a company called Sysinternals.

<!-- S67 -->
Microsoft bought them.

<!-- S68 -->
That was in 2006.

<!-- S69 -->
And they got the man who wrote it.

<!-- S69b -->
Mark Russinovich.
Today, he is the CTO of Azure.

<!-- S70 -->
Microsoft has owned that tool,
and the person who wrote it,
for twenty years.

<!-- S71 -->
They host the download themselves.

<!-- S72 -->
And it is still not in Windows.

<!-- S73 -->
So the answer cannot be
that Microsoft couldn't.

<!-- S74 -->
Which means the real question
was never why they failed.

<!-- S75 -->
It's why they chose not to.

<!-- S76 -->
There are three explanations.

<!-- S76b -->
Only one of them has court records.
Keep an eye on which.

<!-- S76c -->
The first is the one
everybody already knows.

<!-- S77 -->
Windows was sold as a platform.

<!-- S78 -->
Microsoft did not want to own
every application on your computer.
They wanted to own the floor
it all stood on.

<!-- S79 -->
Need a file manager?
Somebody will build one.
Need a disk tool?
Somebody will build one.

<!-- S80 -->
And that worked spectacularly.

<!-- S81 -->
But on its own it explains nothing,
because Apple sells a platform too,
and Apple ships a screenshot tool.

<!-- S82 -->
So here is the second reason,
and this one has court dates.

<!-- S83 -->
In 1998,
the American government
took Microsoft to court.

<!-- S84 -->
Not for writing a bad browser.

<!-- S85 -->
For putting it in Windows.

<!-- S86 -->
A judge ordered the company
to be split in two.

<!-- S86b -->
That order was thrown out on appeal,
and the case settled in 2001.

<!-- S86c -->
And the question underneath it,
whether putting the browser in Windows
was legal at all,
was never actually answered.

<!-- S87 -->
Then in 2004,
the European Commission fined them
nearly half a billion euros.

<!-- S88 -->
And ordered them to ship
a version of Windows
with the media player taken out.

<!-- S89 -->
Look at that sentence again.

<!-- S90 -->
A regulator required Microsoft
to remove a tool from Windows.

<!-- S91 -->
And this is not ancient history.

<!-- S92 -->
Starting in 2016, an antivirus company
complained to regulators in Russia,
then in Germany, then in Brussels.

<!-- S93 -->
Because Windows had started
defending itself.

<!-- S93b -->
They withdrew the complaints in 2017,
once Microsoft agreed
to change how it behaved.

<!-- S94 -->
So put yourself
in that meeting room.

<!-- S95 -->
Somebody proposes shipping
the best archive tool on the market,
for free, to a billion machines.

<!-- S96 -->
There is a market for archive tools.

<!-- S97 -->
Shipping the best possible tool
is the most expensive thing
Microsoft can do.

<!-- S97b -->
And only for Microsoft.
A smaller company could ship
exactly the same tool and be fine.

<!-- S97c -->
Once you are dominant, competition law
limits how you can use that position.
And replacing the very companies
that built their business on your platform
can start to look a lot like abusing it.

<!-- S97d -->
Microsoft was trapped
by its own success.

<!-- S98 -->
And the third reason
is the quietest one.

<!-- S99 -->
Putting something in Windows
means supporting it
for the next twenty years.

<!-- S100 -->
It has to keep working.
It can never be removed.
It becomes somebody's whole workflow
by Thursday.

<!-- S101 -->
Which is why, in 1996,
Microsoft did something revealing.

<!-- S102 -->
They released a set of their own
Windows utilities called PowerToys.

<!-- S103 -->
Written by Microsoft engineers.
Downloaded separately.
And officially unsupported.

<!-- S104 -->
We made these.
They're good.
We are not putting them in the box.

<!-- S105 -->
And that same rule
explains the biggest gap of all.

<!-- S106 -->
Twenty programs.
Twenty updaters.
One checks at startup.
One installs a service.

<!-- S107 -->
You log in on a Monday
and six of them want your attention
before you have opened anything.

<!-- S108 -->
Linux solved this decades ago.
One command updates everything.

<!-- S109 -->
So why couldn't Windows?

<!-- S110 -->
Because that command works
for a reason people forget.

<!-- S111 -->
A Linux distribution
builds the software itself.
It compiles it, packages it,
and knows what is in it.

<!-- S112 -->
Microsoft does not build your software.

<!-- S113 -->
Windows is not a distribution.
It is a floor that anyone
may put anything on.

<!-- S114 -->
Which is exactly why
that installer-watching program existed.

<!-- S115 -->
Nobody had the list.
Not even Windows.

<!-- S116 -->
So that is the answer.
Platform, lawsuits, and the weight
of anything you put in the box.

<!-- S117 -->
Except something has changed.

<!-- S118 -->
Because Windows now has
a package manager.

<!-- S119 -->
It arrived in 2021.
One command,
and your programs update.

<!-- S120 -->
Windows has a proper terminal now.
It runs Linux.
PowerToys came back in 2019,
open source.

<!-- S121 -->
So why now?

<!-- S122 -->
Partly because the thing
being protected has moved.

<!-- S123 -->
Windows is not where
Microsoft makes its money any more.

<!-- S123b -->
It now sits in the smallest
of the company's three divisions.

<!-- S123c -->
That division brings in
less than a fifth of the revenue.
It also contains the Xbox.

<!-- S124 -->
And nobody is going to court
over a screenshot tool.

<!-- S125 -->
The fight moved to browsers,
then to phones,
then to the data centre.

<!-- S126 -->
The desktop is no longer
the thing being defended.

<!-- S127 -->
But look closely at what shipped.

<!-- S128 -->
PowerToys, you download yourself.
Process Explorer, you download yourself.
Sysinternals, you download yourself.

<!-- S129 -->
Thirty years later,
Microsoft still keeps its best tools
one step outside Windows.

<!-- S130 -->
So the strange result stands.

<!-- S131 -->
Microsoft built a platform
so successful
that other people built
everything missing from it.

<!-- S132 -->
And because those tools existed,
Microsoft never had to.
And for years,
doing too much carried legal risk.

<!-- S132b -->
Windows turned out to be
extraordinarily good at hosting
the tools it never shipped itself.

<!-- S133 -->
The user paid for that in complexity.
A better file manager.
A better search.
Every one of them updating separately.

<!-- S134 -->
Which means the real Windows experience
was never install it and you're done.

<!-- S135 -->
It was: install Windows.

<!-- S136 -->
Then build your own
operating environment around it.

<!-- S137 -->
And the strangest part isn't
that Microsoft couldn't do it.

<!-- S138 -->
It's that for twenty years,
being brilliant at this
was the one thing
Windows could not afford to be.
