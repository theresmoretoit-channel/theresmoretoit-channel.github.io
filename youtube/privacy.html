Privacy policy – There's More To It publishing toolkit

Last updated: 19 October 2026

This toolkit is a set of scripts used only by the owner of the YouTube channel “There's More To It” to manage that channel. It uses YouTube API Services. By using it, the user agrees to be bound by the YouTube Terms of Service and the Google Privacy Policy.

The toolkit accesses only the data of the YouTube channel whose owner has signed in with their own Google account: video metadata, captions, playlists and channel statistics. It does not access, collect or store data about any other person or channel. The data is stored only on the owner's own computers and in the owner's private repository, it is not shared with anyone, and it is used only to manage the channel.

Access can be revoked at any time at https://security.google.com/settings/security/permissions. Stored data is deleted on request within 30 days; contact: theresmoretoit.channel@gmail.com.
